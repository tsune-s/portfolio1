## 概要

このポートフォリオは、**データ収集から分析、機械学習モデル構築、デプロイメント**まで、データ分析の全工程を実装した実践的なプロジェクトです。

### 🎯 このポートフォリオで示すスキル

- **データエンジニアリング**: ETLパイプライン設計、データ品質管理
- **機械学習**: 分類モデル構築、ハイパーパラメータ最適化、モデル評価
- **データ可視化**: 統計的可視化、インタラクティブダッシュボード
- **ソフトウェア工学**: モジュール設計、テスト駆動開発、ドキュメント作成

## クイックスタート

### 前提条件
- Python 3.12以上
- uvパッケージマネージャー（推奨）

### セットアップ手順

1. **リポジトリのクローン**
```bash
git clone <repository-url>
cd portfolio
```

2. **依存関係のインストール**
```bash
uv sync
```

3. **サンプルデータの生成**
```bash
uv run python main.py --generate-data
```

4. **機械学習モデルのトレーニング**
```bash
uv run python main.py --train-model
```

5. **ダッシュボードの起動**
```bash
uv run python main.py --dashboard
# または
uv run streamlit run dashboards/app.py
```

ブラウザで `http://localhost:8501` にアクセスしてダッシュボードを確認できます。

### テストの実行

```bash
uv run python main.py --test
# または
uv run pytest tests/ -v
```

## 実装プロジェクト

### 1. 顧客チャーン予測 🔄

**目的**: 解約リスクの高い顧客を予測し、事前の対策を可能にする

**実装内容**:
- 顧客属性、利用パターン、課金情報からの特徴量エンジニアリング
- XGBoost、LightGBM、Random Forestの比較
- SHAP値による説明可能性の実装
- インタラクティブな予測ダッシュボード

**モデル性能**:
- 精度（Accuracy）: **75.4%**
- 適合率（Precision）: **71.6%**
- 再現率（Recall）: **75.4%**
- F1スコア: **72.3%**
- ROC AUC: **75.5%**

**ビジネスインパクト**:
- 契約タイプが最重要特徴（月額契約は解約率が高い）
- 在籍期間6ヶ月未満の顧客は要注意
- サポート通話数と解約率の相関を発見

### 2. 売上予測システム 📈

**目的**: 時系列分析により将来の売上を予測

**実装内容**:
- トレンド・季節性の分解
- 複数の予測モデル（ARIMA、Prophet、LSTM）の比較準備
- カテゴリー別売上分析
- リアルタイム予測ダッシュボード

**分析結果**:
- 明確な年次・週次の季節性パターンを検出
- カテゴリー別の成長トレンドを可視化
- 休日・イベントの影響を定量化

### 3. マーケットバスケット分析 🛒

**目的**: 購買パターンを発見し、商品推薦・レイアウト最適化に活用

**実装内容**:
- Aprioriアルゴリズムによる関連ルール抽出
- 商品間のネットワーク可視化
- レコメンデーションエンジン
- インタラクティブな探索ダッシュボード

**発見された主な関連**:
- 牛乳 → 卵、パン、バター
- コーヒー → 砂糖、牛乳
- パスタ → トマト、玉ねぎ

## 技術的な特徴

### 1. データパイプライン設計

```
生データ → データ検証 → 前処理 → 特徴量エンジニアリング → モデル学習 → 評価 → デプロイ
```

**実装した機能**:
- 複数データソース対応（CSV、JSON、SQL、Webスクレイピング）
- 自動データ品質チェック
- 欠損値処理の自動化
- 外れ値検出・除去
- カテゴリカル変数のエンコーディング
- 数値特徴量のスケーリング

### 2. 機械学習パイプライン

**モデル開発フロー**:
1. データ分割（Train/Test）
2. 複数アルゴリズムの比較評価
3. クロスバリデーション（5-fold）
4. ハイパーパラメータチューニング
5. 最終モデルの学習・評価
6. モデルの保存・シリアライズ

**実装した最適化手法**:
- Grid Search
- Randomized Search
- 交差検証による汎化性能の評価

### 3. コード品質管理

- **型ヒント**: 全関数に型アノテーションを実装
- **Docstrings**: Google Style Docstringsで詳細な説明
- **単体テスト**: Pytestによるテストカバレッジ
- **コード整形**: Blackによる自動整形
- **静的解析**: Ruffによるリント
